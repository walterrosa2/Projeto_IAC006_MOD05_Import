# Pacote de Documentação — Classificador Contábil com IA

Este pacote contém os documentos base para desenvolvimento na IDE agentic Antigravity.

## Arquivos

1. `01_PRD_MVP_Classificador_Contabil.md`  
   Documento de requisitos do produto, com escopo, telas, regras de negócio e critérios de aceite.

2. `02_Arquitetura_Tecnica_IDE.md`  
   Arquitetura técnica para orientar implementação.

3. `03_Plano_Execucao_Backlog.md`  
   Plano de tarefas, fases, backlog e critérios de conclusão.

4. `04_Instrucao_Agentic_Antigravity.md`  
   Prompt/instrução operacional para colar ou anexar no agente da IDE.

5. `AGENTS.md`  
   Regras persistentes para agentes dentro do repositório.

## Uso recomendado

1. Criar um novo repositório/projeto.
2. Criar pasta `docs/`.
3. Colocar os arquivos 01 a 04 dentro de `docs/`.
4. Colocar `AGENTS.md` na raiz do repositório.
5. Pedir ao agente da IDE para executar a Fase 0 do plano de execução.
6. Validar cada fase antes de avançar.
